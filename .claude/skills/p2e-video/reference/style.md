# 画面和声音规范

组长的四个片段（01、04、06、08）和个人视频都按这套规范做，所有人照做，拼起来才像一个视频。
成品在组长本地（视频文件不放进仓库），想看效果可以向组长 HU YANZHI 要。

## 画面

| 项目 | 规定 |
|---|---|
| 尺寸 | 1920×1080，30 fps，H.264（`p2e_video.py render` 已固定） |
| 背景 | 纯白 `#fff`，不要渐变、花纹、暗色页面 |
| 颜色 | 正文 `#16202c`，次要 `#6b7380`，强调蓝 `#1565c0`，对 `#2e7d32`，错 `#c62828`；A/B/D 不另配色 |
| 字号 | 大标题 72–84 px，正文 ≥ 36 px，注释 ≥ 26 px；观众看的是缩小后的画面 |
| 左上角标签 | 每个场景 `data-tag="<b>片段号</b>主题"`，如 `<b>05</b>Tasks · ReproSpec` |
| 字幕区 | 底部 140 px 留给字幕，画面内容不要放进去 |
| 字幕样式 | `base.css` 的 `#sub`：深色半透明圆角框、白字 38 px、两行时自动平衡；不要另做 |
| 截图 | demo 页面截图放大到能看清卡片文字（例子里放大 1.5 倍）；需要指给观众看的地方用蓝色圆角框 + 蓝底白字标签 |

## 时间

- **场景切换放在停顿里**：`transcribe` 输出的 `pauses.txt` 里每个停顿 "a-b"，切换时刻取 b 前 0.3 s 左右；绝不在一句话中间切。
- **元素跟着词出现**：某个词在 `words.csv` 里是 t 秒，对应元素的 `data-t` = t − 场景开始 − 0.2。
  语音识别的单词时刻有 ±0.3 s 误差，用停顿结束时刻校准（停顿结束 = 下一句真正开口）。
- 片段长度 = 录音长度 + 约 0.5 s；小组片段不能超过分配的时长（短一点没关系）。
- 不改音频的时间轴：不剪停顿、不变速，否则字幕和画面全错。

## 声音

| 项目 | 规定 |
|---|---|
| 响度 | 小组片段 **-16 LUFS**，个人视频 **-14.4 LUFS**（和组长成品一致）；`build` / `level` 的 `--target` |
| 句间音量 | `build` 逐句拉平，句间差 ≤ 1 LU；它会打印每句前后的响度，检查一下 |
| 峰值 | ≤ -1 dBFS（限幅器已设） |
| 降噪 | 高通 80 Hz + 轻度 FFT 降噪；录音本身底噪很大（> -50 dB）就请对方换安静地方重录，后期救不回来 |

## 字幕

- 每句一条，时间 = 这句开口到说完（用停顿表），两条之间留出停顿，不连在一起。
- 文字用稿子原文，不用语音识别的结果（会把 ReproSpec 听成 "new prospect"、CORE-Bench 听成 "core range"）。
  如果对方实际念的和稿子不一样（多了 "the"、换了个词），字幕跟实际念的走。
- 数字和术语统一：`SHA-256`、`ReproSpec`、`CORE-Bench`、`McNemar`、`7.6`、`p ≥ 0.25`。

## 交付

每个片段交三个文件：`NN_topic_Name.mp4`（无字幕，拼小组视频用）、`NN_topic_Name_subtitled.mp4`、`NN_topic_Name.srt`；
个人视频是 `personal_Name.mp4` / `personal_Name_subtitled.mp4` / `.srt`。发给组长 HU YANZHI 拼接。
